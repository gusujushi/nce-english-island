# 🏝️ 新概念英语能力岛（1–4 册）

一个在电脑浏览器里运行的英语学习程序。它把你下载的**新概念英语第一至第四册**（原声 MP3 + 课文）变成闯关式学习：

- 全程英式发音
- 彩色句子分析
- 每课 6 步学习法
- 学习计划可调：默认 30 天学完四册，也能改成 60 / 90 / 120 天

## 怎么打开

双击 `dist/新概念英语能力岛.html`，推荐用 **Microsoft Edge** 打开，它自带英式自然语音 Sonia / Ryan；Chrome 也可以。不需要安装，也不需要联网。

开发版在 `app/index.html`。改完代码后运行 `python3 build.py`，会同时重新生成电脑单文件版和手机版。

## 📱 手机版（添加到桌面，像 App 一样用）

`docs/` 目录是手机版，由 `python3 build.py` 生成。添加到桌面后：

- 有桌面图标，打开就是全屏，没有浏览器地址栏
- 可以离线使用
- 底部有导航栏；精读时点一句话，分析会从底部弹出
- 导入的课文和音频保存在手机里，下次打开直接播放，不用重新导入

**第一步：把 `docs/` 发布成网址（只需做一次）**

1. 打开仓库的 **Settings → Pages**。
2. Source 选 **Deploy from a branch**，Branch 选 `main`，文件夹选 **`/docs`**，点 Save。
3. 等 1–2 分钟，页面上方会显示网址：`https://gusujushi.github.io/nce-english-island/`

> 私有仓库要用 GitHub Pages，需要付费的 GitHub Pro。如果 Pages 页面提示要升级，可以在 Settings → General 最下面把仓库改成 Public（公开）。仓库里没有课文原文和录音，只有程序和学习资料。

**第二步：在手机上添加到桌面**

- **iPhone**：必须用 **Safari** 打开上面的网址 → 点底部的分享按钮 ⬆️ → 选「添加到主屏幕」→ 点「添加」。
- **安卓**：用 **Chrome** 打开网址 → 点「安装到桌面」按钮，或者菜单 ⋮ →「添加到主屏幕 / 安装应用」。

**第三步：把新概念文件导入手机**

1. 先把 MP3 和 LRC 文件放进手机：iPhone 放进「文件」App，安卓放进「下载」文件夹。网盘里的文件先下载到本地。
2. 打开 App → 底部「我的」→「我的课文文件」。
3. **一册一册导入**：先在「这次导入的是」里选好册数，再点「选择文件」，进到这一册的文件夹后**全选** MP3 和 LRC。
4. 「把导入的音频保存到本机」默认是勾上的。四册音频一共要占几百 MB，请留出手机空间。

**英式语音**

- iPhone：打开「设置 → 辅助功能 → 朗读内容 → 声音 → 英语」，下载一个英国口音的声音（如 Daniel、Kate）。
- 安卓：打开「设置 → 文字转语音输出」，安装“英语（英国）”语音数据。

## 第一次使用

1. 打开程序 → 左侧「📂 我的课文文件」→「选择文件夹」→ 选中 **下载 / Downloads** 里的新概念英语文件夹。可以选包含四册的总文件夹，也可以一册一册导入。
2. 程序会自动判断**第几册、第几课**：
   - 文件夹名或文件名：「新概念英语第二册」「NCE2」「Book 3」「第三册」等
   - 课文标题：例如文件名里带 “A private conversation”
   - 第一册的单、双数课（如 `001&002.mp3`）合成一个学习单元
   - 认不出时可以设置“默认册数”，或手动给每个文件指定册数和课号
3. 支持的文件格式：
   - **MP3 / M4A / WAV**：原声音频
   - **LRC 歌词**（推荐）：带时间轴，能逐句播放原声；双语 LRC 会自动分出中文译文；GBK / UTF-8 编码都能读
   - **TXT / PDF**：整本或单课都行，按 “Lesson N” 自动拆分。PDF 需要联网加载解析组件
4. 文件只在浏览器本地读取，不会上传。课文文本会被记住；下次打开时，点「🔗 重新连接上次的文件夹」就能找回音频。

## 学习计划

- 每 5 天为一轮：前 4 天学新课，第 5 天复习通关。
- 程序**按难度分配**每天的课：第一册一天可学二十多个单元，第四册一天学一两课。
- **默认 30 天学完四册**，平均每天约 4 小时，强度很大。时间不够的话，在「设置与计划」里改成 60、90（推荐）或 120 天，也可以只选某几册。已完成的进度不会丢。

## 每课 6 步

1. **🎧 导读盲听**：不看原文先听；读通俗中文导读、读法建议和英音提示
2. **🔤 英音词汇**：核心词的英式音标、发音，以及它们在你课文原文里的例句
3. **🔍 逐句精读**：逐句播放原声。点任意一句，看彩色结构、意群切分、主干提示、语法点和生词；点任意单词，看英式发音和释义
4. **🧩 语法透视**：自动扫描全文出现的语法现象，配原文例句；攻克本课最长的 3 句
5. **🗣️ 影子跟读**：逐句或按意群跟读，可以录音和原声对比，也有自动跟读模式
6. **🏆 闯关测验**：词义、听音选词、原文填空、听写，60 分过关

另外还有 **⭐ 生词本**（间隔重复复习），以及明亮、暗夜两种彩色主题。

## 彩色句子分析

- 紫色：连接词、从句引导词
- 红色：谓语
- 绿色波浪线：非谓语（to do / doing / done）
- 蓝色：介词
- 黄底：本课重点词
- 第一、二册还会标出基础语法：be 动词句型、疑问句、祈使句、There be、进行时、一般现在时、过去时、将来时等

自动分析按规则判断，只能当提示。长难句可以请 AI 老师精讲。

## AI 老师（可选）

在「设置与计划」里填入你自己的 Claude API Key，就能让 AI 用通俗中文逐句讲解：

- 译文和句子主干
- 结构拆解
- 重点词（英式音标）
- 英音朗读提示

它还能生成整课导读。这个功能需要联网，按 Anthropic 官方价格计费。讲解结果会缓存在本机，同一句不会重复扣费。

## 说明

- 课文原文和录音的版权属于原出版方。本程序**不包含**课文原文，只读取你电脑里已有的文件。
- 内置的是学习资料：每课的中文导读、核心词表（英式 IPA）、语法重点和英音提示。少数课的导读只写了主题和读法，没有展开具体情节。
- 学习进度保存在浏览器本地。换电脑前，请在「设置与计划」里导出备份。

## 文件结构

```
app/
  index.html        页面
  css/style.css     彩色主题（明亮 / 暗夜）
  data/core.js      课程资料结构
  data/book1.js …   各册导读、词汇、语法重点
  js/grammar.js     语法库与句子自动分析
  js/parser.js      文件读取：识别册数和课号，解析 LRC / SRT / TXT / PDF
  js/app.js         主程序
  icons/            手机桌面图标（由 tools/make_icons.py 生成）
build.py            打包：电脑单文件版 + 手机版
dist/               可直接双击打开的单文件版
docs/               手机版（PWA），发布到 GitHub Pages
tools/make_icons.py 生成桌面图标
```
